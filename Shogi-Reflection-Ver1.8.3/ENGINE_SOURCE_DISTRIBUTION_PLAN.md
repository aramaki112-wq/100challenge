## Public distribution method — required decision before release

Before a public binary package is shipped, choose and document a durable Corresponding Source delivery method. At minimum preserve:

1. exact source archive matching the binary;
2. exact build scripts/options;
3. toolchain version/provenance;
4. all local modifications, if future versions add any;
5. applicable license and notices;
6. a stable location/method for recipients to obtain the source for the required period;
7. verification that the offered source actually rebuilds the conveyed binary or explains unavoidable nondeterminism.

A moving `master` URL alone is not accepted as this project's traceability record.
