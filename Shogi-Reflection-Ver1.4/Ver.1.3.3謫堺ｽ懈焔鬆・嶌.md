# Ver.1.3.3 操作手順書

## 1. KIFを貼り付ける

1. 対局後、ぴよ将棋等からKIF本文をコピーします。
2. `スマホ：KIF本文を貼り付け`欄を長押しし、`ペースト`します。
3. 対応ブラウザでは`クリップボードから読み込む`も使用できます。
4. `貼り付けたKIFを確認`を押します。
5. `棋譜読み込み確認`で対局者・結果・手数等を確認します。
6. 正しければ`この内容を入力フォームへ反映`を押します。

この時点では保存済み対局へは保存されていません。

## 2. 間違ったKIFを貼った時

### 全部消してやり直す

`入力をクリア`を押します。

消えるもの：
- KIF貼り付け欄
- 今回の棋譜読み込み確認

消えないもの：
- ClipboardにコピーしてあるKIF
- 保存済み対局
- Repository Data
- LocalStorage Data
- 既存Backup

### Previewから入力へ戻って直す

`棋譜入力へ戻る`を押します。

- Previewは閉じます。
- KIF本文は残ります。
- 修正または別KIFへ貼替えできます。
- もう一度`貼り付けたKIFを確認`を押せます。

## 3. Replay

入力フォーム反映後、棋譜再現盤で`前へ`／`次へ`／`最初へ`／`最後へ`を使用します。通常NavigationではPage全体は棋譜一覧へ自動Scrollせず、必要な追従は棋譜一覧内部だけで行います。

## 4. 重要局面

重要だと思う局面で`この局面を重要局面へ追加`を押します。手数・指し手・局面記録が候補へ入り、事実（FACT）・解釈（INTERPRETATION）・仮説（HYPOTHESIS）は自分で入力します。

重要局面は3〜5件、次局の観察テーマは1件、次局で守るルールは1〜3件です。

## 5. 保存

入力が終わったら`振り返りを保存する`を押します。KIFのPreviewやForm反映だけでは永続保存されません。

## 6. Browser確認の範囲

自動Browser確認はChromium Headlessで390×844を含むViewportで実行しています。実機iPhone Safariを自動操作したという意味ではありません。完成版は実際のスマートフォンで対局後に使用し、最終的な操作感を確認してください。
